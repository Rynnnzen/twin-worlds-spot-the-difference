Twin Worlds — a spot-the-difference game: 8 hand-drawn miniature scenes, 64 differences, a magnifier, three difficulty modes, hints, streak scoring and keyboard play. Two near-identical pictures side by side; every difference is a real one — removed, recolored, moved, resized, flipped, added or replaced — and each found one gets a gold ring on both panels. Everything is drawn in code on a canvas: no images, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ in a desktop browser.
